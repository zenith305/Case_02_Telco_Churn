# 📊 Прогнозирование оттока клиентов телеком-оператора (Telco Churn)

## 📝 Описание проекта
Данный проект посвящен решению задачи бинарной классификации — прогнозированию вероятности ухода (оттока) абонента телеком-компании. 
**Бизнес-цель:** Выявить клиентов из группы риска и определить ключевые факторы, влияющие на их уход, чтобы отдел удержания мог вовремя предложить им специальные условия.

## 📁 Данные
Использован открытый датасет [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) (IBM Sample Data Sets).
*   **Объем:** 7043 строки, 21 признак.
*   **Целевая переменная:** `Churn` (Yes/No).
*   **Особенности:** В исходных данных присутствовал дисбаланс классов (уходит ~26% клиентов) и пропуски в признаке `TotalCharges`.

## 🛠️ Стек технологий и инструменты
*   **Язык:** Python 3.14
*   **Обработка данных:** Pandas, NumPy
*   **Машинное обучение:** Scikit-learn (LogisticRegression, StandardScaler, Pipeline)
*   **Интерпретация моделей:** SHAP
*   **Визуализация:** Matplotlib, Seaborn
*   **Среда разработки:** VS Code, Jupyter Notebooks

## 🚀 Этапы работы (Пайплайн)
1.  **Предобработка (`src/preprocess.py`):** Очистка данных, приведение `TotalCharges` к числовому типу, заполнение пропусков, удаление неинформативного `customerID`.
2.  **EDA (`notebooks/01_eda.ipynb`):** Разведочный анализ. Выявлен дисбаланс классов (73% / 26%) и сильная зависимость оттока от типа контракта.
3.  **Feature Engineering (`notebooks/02_features.ipynb`):** One-Hot Encoding категориальных признаков, разделение выборки на Train/Test (стратифицированно).
4.  **Моделирование:** Обучена `LogisticRegression` с параметром `class_weight='balanced'` для борьбы с дисбалансом. Модель обернута в Pipeline со `StandardScaler`.
5.  **Интерпретация (SHAP):** Построен `shap_summary_plot` для выявления глобальных факторов риска.

## 📈 Результаты
*   **Метрика ROC-AUC:** `0.8414` (отличный результат для baseline-модели).
*   **Recall (класс Churn):** `0.79` (модель успешно «ловит» 79% уходящих клиентов).
*   **Accuracy:** `0.74`.

### 🔑 Ключевые факторы риска (по результатам SHAP-анализа):
1.  **`Contract_Month-to-month`** — клиенты на помесячной оплате уходят чаще всего.
2.  **`tenure`** — новые клиенты (с маленьким стажем) находятся в зоне высокого риска.
3.  **`MonthlyCharges`** — высокий ежемесячный чек провоцирует отток.
4.  **`InternetService_Fiber optic`** — наличие оптоволокна повышает риск ухода (возможно, из-за высокой цены).

*(График факторов риска находится в `reports/shap_summary_final.png`)*
