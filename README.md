📊 Прогнозирование оттока клиентов телеком-оператора (Telco Churn)

📝 Описание проекта
Данный проект посвящен решению задачи бинарной классификации — прогнозированию вероятности ухода (оттока) абонента телеком-компании. 
Бизнес-цель: Выявить клиентов из группы риска и определить ключевые факторы, влияющие на их уход, чтобы отдел удержания мог вовремя предложить им специальные условия.

📁 Данные
Использован открытый датасет Telco Customer Churn (IBM Sample Data Sets).
- Объем: 7043 строки, 20 признаков (customerID перенесен в индекс).
- Целевая переменная: Отток (0 - остался, 1 - ушел).
- Особенности: Дисбаланс классов (уходит ~26.5% клиентов), 22 полных дубликата по признакам (оставлены, так как это разные клиенты).

🛠️ Стек технологий и инструменты
- Язык: Python 3.12
- Обработка данных: Pandas, NumPy
- Машинное обучение: Scikit-learn (Pipeline, ColumnTransformer, LogisticRegression, RandomForest, HistGradientBoosting)
- Интерпретация моделей: SHAP
- Визуализация: Matplotlib, Seaborn
- Среда разработки: VS Code, Jupyter Notebooks
- Сохранение моделей: Joblib

🚀 Этапы работы (Пайплайн)
1. Предобработка (src/data_utils.py): Загрузка, очистка типов, перевод значений на русский язык, оптимизация памяти.
2. EDA (notebooks/01_predzashita.ipynb): Разведочный анализ. Выявлен дисбаланс классов и сильная зависимость оттока от типа контракта и стажа.
3. Моделирование (notebooks/02_zashita.ipynb): 
   - Построение ColumnTransformer (One-Hot Encoding для категорий, StandardScaler для чисел).
   - Сравнение 3 моделей: LogisticRegression (baseline), RandomForest и GradientBoosting.
   - Подбор оптимального порога отсечения (Threshold Tuning) для максимизации Recall (борьба за удержание клиентов).
4. Интерпретация (SHAP): Построен shap_summary_plot для выявления глобальных факторов риска лучшей модели.
5. Экспорт: Сохранение лучшей модели и списка клиентов в зоне риска.

📈 Результаты
- Метрика ROC-AUC: ~0.84 (стабильный результат).
- Настроенный порог отсечения позволил увеличить Recall (модель успешно «ловит» большую часть уходящих клиентов, минимизируя упущенную выгоду).

🔑 Ключевые факторы риска (по результатам SHAP-анализа):
1. Контракт: Помесячный — клиенты на помесячной оплате уходят чаще всего.
2. Стаж — новые клиенты (с маленьким стажем) находятся в зоне высокого риска.
3. Платёж в месяц — высокий ежемесячный чек провоцирует отток.
4. Интернет: Оптоволокно — наличие оптоволокна повышает риск ухода.
5. Способ оплаты: Электронный чек — повышает вероятность ухода.
